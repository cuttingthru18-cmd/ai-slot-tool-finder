# Contributing

Thanks for helping the machine grow. Two ways to contribute:

## Suggest a tool
Open a [tool suggestion issue](../../issues/new/choose). Every entry must clear the quality bar:
1. **Free** (or a genuinely useful free tier — no trials)
2. **Alive** — actively maintained or stable and functional
3. **Safe** — official domain or source repository only
4. **"Whoa"-worthy** — it should amaze a normal person, not just be useful

## Report a dead link
Open a [dead link issue](../../issues/new/choose) with the tool name. Automated checks run weekly, but human reports are faster.

## Pull requests
PRs welcome for fixes and entries. Tools live in the `TOYS` array inside `index.html`:
`{"n":"Name","e":"emoji","c":"fun|candy|agent|creator|win","d":"one-line pitch (max 140 chars)","u":"https://official-url"}`
Update the counts in the page subtitle and README table when adding.
