# Security Policy

This is a static, single-file web app: no backend, no accounts, no data collection. The realistic security surface is the outbound links.

**Report a concern** (a listed tool turned malicious, a link hijacked, or anything in `index.html` itself) by opening an issue — or if it's sensitive, use GitHub's private vulnerability reporting on this repo. Malicious or compromised tools are removed as soon as verified.
